What is CueMyBreak?
An all-in-one platform for managing professional snooker tournaments, tracking head-to-head match histories, and discovering hidden connections between players.
What makes it special?
Instead of just showing tables and lists, it models the entire sporting ecosystem as an interactive connected graph where players, venues, hosts, and matches are linked in real time.

Slide 2 / 7 • Core Concept

Why Did We Use a Graph Database (Neo4j)?

Why traditional SQL databases fail for tournament ladders and player connections

The Problem with SQL (Relational Databases)
To find indirect connections (e.g. "Has Player A ever played against anyone who beat Player B?"), SQL requires multiple expensive JOIN operations across tables. With thousands of matches, queries become extremely slow.
The Neo4j Solution (Index-Free Adjacency)
In Neo4j, relationships are stored as direct memory pointers between nodes. Traversing from one player to their opponents takes less than 5 milliseconds ($O(1)$ per hop).
Knockout Brackets are Natural Graphs
A tournament bracket is a Directed Acyclic Graph (DAG) where winners naturally move to the :NEXT_MATCH. Graphs represent this perfectly without messy join tables.
// Finding indirect connections in Cypher: MATCH (p1:Player {name: 'Rahul Sharma'}) -[:PLAYED_AGAINST*1..3]- (p2:Player {name: 'Ronnie O\'Sullivan'}) RETURN p2.name, length(path) AS Degrees; // Result in 2ms: Rahul Sharma → Aditya Verma → Ronnie O'Sullivan (2 hops)
⚡ Index-Free Adjacency: Traversals don't slow down as the database grows!
Slide 3 / 7 • Architecture

System Architecture: Polyglot Database Design

Using the right tool for the job: Neo4j for relationships + MongoDB for documents

1. Frontend (React + Vite + Tailwind + D3.js)
Modern dark-theme user interface with interactive physics-based force graph canvas, live query studio, and live match scoring controls.
2. Backend (Node.js + Express + TypeScript)
REST API server managing business logic, bracket generation, and dual-database synchronization.
3. Neo4j Graph DB (Relationship Engine)
Stores 152 nodes and 444 relationships. Runs Cypher queries, shortest paths, PageRank, and bracket progression.
4. MongoDB Document DB (Document Engine)
Stores frame-by-frame ball potting telemetry, player bios, and detailed tournament rules.

Slide 4 / 7 • Data Model

Our Graph Schema: 7 Node Labels & 10 Relationships

A complete model covering players, venues, hosts, and tournament stages

7 Node Labels (152 Nodes Total)
🟢 Player (40 nodes): name, currentRank, winRate, highestBreak
🟣 Venue (10 nodes): name, city, tableCount, seatingCapacity
🔵 Host (6 nodes): name, organization, email, phone
🟡 Event (12 nodes): title, format, status, entryFee
🟠 Tournament (6 nodes): name, status, prizePool, numRounds
⚪ Round (18 nodes): roundNumber, tournamentId, status
🔴 Match (60 nodes): matchId, scoreA, scoreB, status, winnerId
10 Relationship Types (444 Links Total)
↔️ PLAYED_AGAINST: Connects two players with head-to-head stats
🏆 PARTICIPATED_IN: Connects a player to a tournament
🥇 WON / LOST: Connects a player to a match result
📍 HOSTED_AT: Connects a tournament/event to its physical venue
👔 MANAGED_BY: Connects a tournament to its organizing host
📝 REGISTERED_FOR: Connects a player to a tournament event
🪜 HAS_ROUND / HAS_MATCH: Tournament bracket hierarchy
➡️ NEXT_MATCH: Advances match winners to the next knockout round
Slide 5 / 7 • Interactive Feature

Interactive Graph Explorer & Shortest Path

Visual network exploration with live Dijkstra/BFS shortest path calculation

D3.js Force Simulation Canvas
Allows users to zoom, pan, and drag any of the 152 nodes in real-time with physics-based collisions and link tension.
"Go to a node" Dropdown Navigator
Select any node directly from the dropdown to focus and view its exact properties (Rank, Win Rate, City, Tables).
Directional Connections List
Shows incoming (← MANAGED_BY) and outgoing (HOSTED_AT →) links. Clicking any item jumps to that connected node immediately.
Shortest Path Finder (Degrees of Separation)
Select Player 1 and Player 2 $\rightarrow$ highlights their shortest path in glowing amber color while dimming other nodes.

Slide 6 / 7 • Intelligence & Cypher

Cypher Query Studio & Graph Analytics (GDS)

Write custom queries live in the browser + 3 advanced graph algorithms

Live Cypher Query Editor
You can type any Cypher query on screen and click "Run Cypher". It executes instantly and renders formatted result tables with millisecond execution latency.
1. PageRank Centrality (Player Dominance)
Measures player strength based on who they beat. Defeating a top-tier player (like Ronnie O'Sullivan) gives far more score than beating a lower-ranked player.
2. Louvain Community Detection
Automatically groups players into competitive tiers and circuits without any manual human labeling.
3. Shortest Path (Degrees of Separation)
Finds the shortest historical match chain connecting any two players in the ecosystem.
